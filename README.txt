TUGAS RUTIN 7 - SISTEM LOGIN/REGISTER PHP NATIVE

File:
index.php, register.php, login.php, dashboard.php, logout.php, style.css, data/users.json

Cara menjalankan:
1. Jalankan Apache di XAMPP.
2. Ekstrak folder ke C:\xampp\htdocs\
3. Buka http://localhost/Tugas_Rutin_7_Login_Register/
4. Register akun, lalu login.

Pengujian:
- Register valid
- Email duplikat
- Password < 6 karakter
- Konfirmasi password berbeda
- Login benar/salah
- Akses dashboard sebelum login
- Logout
- Remember Me
- Cek users.json: password tersimpan sebagai hash
